## 同步文件夹

- 同步途中刚保存的内容会保留。对方准备覆盖、删除或创建同名文件时，PolySync 在写入前核对磁盘内容。文件已经变化就结束本轮，下一轮按新的内容核对，发生冲突时保留版本。
- 一个文件夹可邀请多台设备。选择「共同编辑」可以互传修改。选择「仅接收」可以让设备跟随一个指定上游。上游以后开启回传时，跟随设备先核对将要同步的新增、修改和删除。
- 设备按照各自确认的连接传递更新。需要两台协作设备在第三台关机时继续直连，可以为这两台建立同一文件夹的连接。旧版两端文件夹仍可继续使用。
- 可以单独断开某条文件夹连接，也可以从「管理设备」取消本机与某台设备的配对。确认框会列出影响范围，本地文件保留。

## 使用体验

桌面端从「添加同步文件夹」开始，配对完成后直接回到刚才的邀请。只有一台合适设备时会预选。随传记录分批显示，任务进度和后台刷新保留键盘焦点与滚动位置。桌面控制台和下载页支持深浅色、窄窗口以及系统的减少动态效果设置。

Android 实验版支持独立的应用内工作区。新版包可与 dev.4 并装，使用独立的配对身份和工作区。原工作区仍在旧应用中，需要的文件可从旧应用导出到新工作区。

## 下载与升级

Windows x64 推荐 MSI，另有便携 EXE。Ubuntu 提供 amd64 和 arm64 安装包，Arch 提供 x86_64 安装包。macOS 提供 Apple 芯片和 Intel 两种程序。原安装渠道升级时，先等任务结束并退出旧程序，继续使用原数据目录。Windows 安装包和 macOS 程序尚未做发布者签名。下载后的 SHA-256 可在同页校验清单中核对。
