# 一个文件夹与多台设备同步

在已配对的设备中发起文件夹邀请。选择「共同编辑」，两端的新增、修改和删除都能传播。选择「跟随」，该设备从邀请方接收更新。每台跟随设备只连接一个上游。角色按文件夹设置，同一台电脑可以在不同文件夹中承担不同角色。

## 谁和谁直接同步

- 在现有文件夹中添加成员即可沿用同一份本地文件。已加入该组的协作设备收到另一个协作成员的邀请时，接受后继续使用现有目录。
- 假设 A 分别邀请了 B 和 C。A 在线时，B 的修改可以经过 A 到达 C。希望 A 关机时 B 和 C 仍能互通，请先让 B 和 C 配对，再由 B 在已有文件夹中邀请 C 共同编辑。C 接受后，三台电脑中任意两台在线都可以交换修改。
- 一轮同步依次联系本机已获准直连的成员。单个成员不在线时，其他成员仍会尝试同步。结果中会写出已同步的设备数和需要重试的连接。
- 在某台设备移除文件夹成员，只撤销这两台设备之间的本机授权。原有文件、历史、设备配对和其他直连关系保留。例如要让 C 完全退出三角形的协作组，可以直接在 C 移除该文件夹配置，或在 A、B 分别断开与 C 的文件夹连接。
- 取消设备配对会撤消这台设备在本机所有文件夹中的直接访问权限。其他成员可继续同步。双方需要重新配对并接受文件夹邀请才能再次交换文件。

## 跟随设备上的本地修改

默认只接收。跟随设备自行保存的新文件、更改或删除的文件仅在本机生效。反复同步时，上游未变化的文件仍保留本机状态。上游后来修改或删除同一路径时，本机跟随上游更新。被替换的本地内容进入该文件夹的历史目录。

如需回传，可以在首次邀请中明确允许，跟随设备接受邀请后生效。对已经加入的跟随设备开放回传时，上游先更改该成员的授权。下一次同步后，跟随端可查看待回传的新增、修改和删除，再确认开启。预览列出各类总数和按路径排序的前 50 项。确认之前如有文件变化，需要重新预览。关闭后，下次连接会在交换清单前撤销写入权限。上游已接收的修改会沿协作关系继续传播。

## 离线、冲突和恢复

每个路径保存各副本的版本计数和删除记录。离线设备带着旧文件重新加入时，已经传播的删除仍然生效。两台设备分别编辑了同一个文件时，内容摘要决定哪个版本保留原名，另一版本保留在同目录的冲突副本中。如果预定的副本名已被用户文件占用，会自动选择另一个名字。并发修改与删除时，保留修改过的文件并记录冲突。每次冲突独立记录。双方能核对共同祖先的版本和内容时，合并窗口也会提供该版本。协作设备确认应用后，处理结果可经其他协作设备转发，关闭其他设备上对应的待处理项。只读跟随设备可以接收处理结果。

删除记录和已处理冲突随组清单持久保存，目前没有自动压缩。

接收的文件先写入本机内容缓存并核验摘要。替换和删除工作目录中的文件前会验证扫描时的内容。同步期间再次保存的文件会引发重试。发生中断时，只采用确实落盘的版本记录。移除配置、重新接受相同文件夹并选择新目录后，会从新的本地副本开始同步。

## 旧版兼容

旧的双端空间可继续使用原协议。原有成员关系保留，在同一文件夹添加新版成员即可扩展。首次邀请共同编辑时，如果对方明确返回不支持组协议，邀请方会改用旧版双端邀请。向旧版发起跟随邀请、或把旧版作为新增组成员时，会提示升级。旧协议连接沿用按双端基线同步的行为，协作网中的版本向量与独立直连需要双方支持新版。设备换网后，只要旧端能向本机确认邀请或发起一次同步，本机会根据这条已验证的连接更新该成员的地址，随后可以主动连回。

v0.5.2 可与 v0.5.0 共同编辑和处理双方都见过的冲突。若一条旧冲突只经过 v0.5.0 中继，且中继没有保存这条冲突的记录，请让仍保有该记录的两台设备直接同步一次。全部设备升级后，新产生的冲突处理结果可随文件版本在协作设备之间转发。

## 本地 API

| 请求 | 内容与结果 |
| --- | --- |
| POST /api/shares/invite | 新文件夹传 path、name、deviceId、role 和可选 allowWriteBack，返回 id。role 可取 collaborator 或 follower。省略 role 沿用双端接口。 |
| POST /api/shares/{id}/members | 传 deviceId、role、allowWriteBack 添加成员。遇到网络错误，409 返回已有的 id 与原因，使用同一请求可重发待处理邀请。 |
| POST /api/share-invitations/{id}/accept | 新文件夹传本地 path。已加入同组时可以传空对象沿用原目录。 |
| PUT /api/shares/{id}/members/{deviceId} | 上游传 allowWriteBack 开放或收回某个跟随设备的回传授权。 |
| GET /api/shares/{id}/writeback-preview | 跟随端取得 added、modified、deleted 总数，paths 的前 50 项及绑定本次内容和授权的 token。 |
| POST /api/shares/{id}/writeback-confirm | 跟随端传 token 确认，内容或授权已有变化时返回 409。 |
| DELETE /api/shares/{id}/members/{deviceId} | 撤销这台设备在此文件夹中的本机直连授权。 |
| GET /api/status | shares 内可读取 localRole、members，成员含 deviceId、role、state、allowWriteBack、writeBackPending，旧协议成员另带 legacy。 |
