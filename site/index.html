安装、更新与校验

Arch Linux：点击上方安装包下载，在下载目录打开终端，运行 sudo pacman -U ./polysync-0.4.0-1-x86_64.pkg.tar.zst，然后从应用菜单打开。无需注册 AUR。

Ubuntu：下载与你的架构匹配的 DEB，双击安装。也可在终端输入 sudo apt install ./ 后接下载的文件名。

更新：先退出旧程序，下载新版安装包再次安装。原安装渠道升级会保留配对和文件。

Windows：推荐 MSI 安装包；免安装 EXE 也可下载。

Linux 通用版 / macOS：对下载的程序运行 chmod +x 文件名，再启动程序。

macOS：当前版本未进行 Apple 开发者签名，首次运行可能需要在“隐私与安全性”中确认。
